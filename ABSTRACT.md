# Abstract

**Airbnb Clone · Earth-1610 Edition: A Client-Side Vacation Rental Platform with Smart Travel Features**

Online vacation rental platforms such as Airbnb have changed how people find and book places to stay, but they still leave many travel-planning tasks to the guest. Comparing stays, finding the cheapest dates, splitting costs with friends, judging whether a place suits remote work, and packing for a trip all happen outside the platform. This project recreates the core Airbnb web experience and extends it with 15 features that the original website does not offer.

The application is a single-page web app built with HTML, CSS and vanilla JavaScript, with no build step, framework or backend. It reproduces Airbnb's main flows: destination search with suggestions, a two-month date-range picker and guest selector, category browsing, a filters panel with a price histogram, listing cards with photo carousels, an interactive map view (Leaflet and OpenStreetMap), detailed listing pages, host messaging, a demo checkout, trips, wishlists, hosting a new listing, and a responsive mobile layout. All user data (account, trips, wishlists and reward points) is saved in the browser's localStorage.

The new features include a Smart Stay Match quiz that scores listings against the guest's preferences, side-by-side comparison of up to three stays, a price heatmap calendar with a cheapest-dates finder, a bill-splitting tool, Eco and Work-from-stay scores, a neighbourhood vibe meter, nearby places with travel times, voice search using the Web Speech API, an auto-generated packing list, calendar (.ics) export, a travel rewards system with points, tiers and badges, a "Surprise me" option, and dark mode.

The project shows that a feature-rich, interactive booking platform can be built entirely on the client side, and that adding decision-support tools can make planning a trip easier. It is an educational project, is not affiliated with Airbnb, Inc., and processes no real payments.

**Keywords:** web application, vacation rental, single-page application, JavaScript, localStorage, Leaflet, Web Speech API, user experience
